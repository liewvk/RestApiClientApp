# RestApiClientApp

A C# application for working with REST APIs.

## Overview

RestApiClientApp is a .NET-based application designed to facilitate REST API interactions and client operations.

## Technologies

- **Language**: C#
- **Platform**: .NET

## Getting Started

### Prerequisites

- .NET Framework or .NET Core (version specific to your setup)
- Visual Studio or compatible C# IDE

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/RestApiClientApp.git
   ```

2. Navigate to the project directory:
   ```bash
   cd RestApiClientApp
   ```

3. Build the project:
   ```bash
   dotnet build
   ```
